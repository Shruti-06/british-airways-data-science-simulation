# Data

The datasets come from the British Airways job simulation on Forage and aren't included in this repo. To run the notebooks, download them from the simulation and save them here with these names:

| File | Used in | Description |
|---|---|---|
| `British_Airways_Summer_Schedule_Dataset.xlsx` | Task 1 | 10,000 Heathrow departures (Apr–Oct 2025) with seats by cabin and eligible passengers per lounge tier |
| `customer_booking.csv` | Task 2 | 50,000 customer bookings with trip details and whether the booking was completed |
